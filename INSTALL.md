### [Beyond Compare 4 & 5](https://www.scootersoftware.com/download.php)

#### Install manually

Download using the [GitHub .zip download](https://github.com/dracula/beyond-compare-4/blob/master/BCColors-Dracula.zip) option and unzip them.

#### Activating theme

1. Double-click the appropriate settings package for your version of Beyond Compare
    - For BC4, use `BCColors4-Dracula.bcpkg`
    - For BC5, use `BCColors5-Dracula.bcpkg`
2. Click "Finish" on the "Import Settings" window
3. Enjoy!
